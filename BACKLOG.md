## 2. Долги в коде (решение есть, руки не дошли)

- [ ] **`TG_CHAT_ID` не заведён в `web/.env`** — а без него суточный дайджест встреч без времени
      слать некуда: `tickSchedule` его молча пропускает (`telegramConfigured()`). Напоминания и
      переносы игрокам это не трогает — им бот пишет в личку, `TG_CHAT_ID` нужен только служебному
      чату. **Осталось действие Стаса:** вписать в `web/.env` свой user id или id канала (образец —
      `web/.env.example`) и перезапустить приложение. Кодом закрыть нельзя, ключи в репозиторий не
      едут. На Э4 молчание сделано видимым: `/admin/bot?tab=settings` показывает предупреждение,
      пока переменные не заданы.

- [ ] **Статистика игрока не разрезана по турнирам.** `/roster/players/<id>` суммирует все турниры
      разом — последняя незакрытая кросс-турнирная витрина (остальные переехали под
      `/tournaments/<slug>/…` и фильтруются по `divisionId`).
- [ ] **Импорт таблицы сезона узнаёт человека по нику, а не по account_id** — отсюда и берутся дубли
      профилей (`/admin/duplicates` их разбирает, но причину не лечит). Апрув заявки уже матчит по
      `account_id` (`findPlayer`); импорту то же самое мешает делать то, что в таблице сезона номера
      часто нет — нужен шаг обогащения до записи.

- [ ] **Реестр баллов без UI.** `PointsEntry` работает только на TP (`src/lib/tp.ts`).
      Для мест, кастов и стримов начисления интерфейса нет — только руками в БД.
- [x] ~~**`/login/tg` считает вошедшим по куке, не проверяя аккаунт.**~~ Закрыто на Э4 (02.09):
      страница спрашивает `currentAccount()`, то есть тот же источник, что и `/me`. Осталось
      родственное и более мелкое: `isAdmin()` берёт роль из куки без похода в базу (так сделано ради
      dev-автовхода), поэтому у куки удалённого админа вкладка «Админ» в шапке ещё видна — сами
      инструменты закрыты правами и отдают отказ.
- [ ] **Восстановление пароля.** После удаления почтового флоу его нет.
      Возможное продолжение без писем — «сбросить пароль» в панели команды у владельца.
- [ ] **OG-картинки при шеринге.** У отчёта матча есть постоянная ссылка, а превью для соцсетей нет:
      генератор постгейма клиентский (`modern-screenshot`), под серверную OG нужна отдельная реализация.
- [ ] **Опознание в боте — по телеграм-хендлу.** Работает, но хендл человек меняет: сменил — бот его
      не узнаёт, а освободившийся хендл может занять посторонний. Пока меню только читает публичное,
      это терпимо; для чего-то большего нужна настоящая привязка чата к аккаунту.

- [ ] **Архивные команды не спрятаны из пула драфта/студии.** `Team.archivedAt` прячет команду из таба
      «Ростер», но `listTeams`/`listTeamRosters` без аргумента (жеребьёвка, UNDERBEER, студия) архивные
      всё ещё отдают. Если мешает — добавить `archivedAt: null` в безаргументную ветку этих выборок
      (в вариант с `divisionIds` — не трогать: там историческая витрина турнира).
- [ ] **Файлы лого/фото не чистятся при полном удалении команды.** `?mode=purge` сносит запись из БД,
      но `public/uploads/teams/<slug>-*` остаются. Безвредно (осиротевшие файлы), но копятся.

### Принятые отступления (не долг, не трогать без причины)

- **Зеркала имени дивизиона.** `Team.group`, `Series.division`, `GroupEntry.division` остались
  строками: по ним фильтруют полтора десятка выборок. Источник правды — `TournamentEntry`,
  единственный писатель зеркал — `src/lib/tournaments.ts`.
- **Аватар и ник из OpenDota не сохраняем.** Ранг пишем в `Player.rank`, ник в лиге человек выбирает
  сам, аватар Steam живёт по чужой ссылке (`Player.photo` у нас всегда локальный файл).
  И то, и другое показываем оператору справкой.
