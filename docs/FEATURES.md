# FEATURES — что умеет SPIRIT/CTRL

Полный смотр функционала на 17.09.2026: что работает, что в разработке, что сознательно
отложено. Составлено для показа проекта целиком.

Внутреннее имя проекта — LOST, публичное — **SPIRIT/CTRL**.

**Версия для показа** — `docs/presentation/spirit-ctrl.html`: тот же смотр страницей, открывается
двойным кликом с диска, ничего не требует. Она же опубликована по ссылке —
<https://claude.ai/artifact/MZZXGKFQq154am2nPFztDD> (приватная, пока не расшарена).
Правится этот файл — страница пересобирается отдельно, автоматической связи между ними нет.

---

## 1. Что это

Платформа киберспортивной лиги по Dota 2 «под ключ»: публичный сайт сезона, кабинет игрока,
приём заявок, проведение матчей с драфтом, сбор статистики из Dota 2 и служебная часть, которой
лига ведётся изнутри. Не витрина поверх гугл-таблицы: данные живут в своей базе, статистика
приезжает из OpenDota и Steam, графика для трансляций собирается тут же.

Одно приложение, один деплой: Next.js 16 + SQLite, ставится на любой VPS с постоянным диском.

## 3. Публичная часть

### Главная

Первый экран лиги. Показывает **все** турниры каждого статуса (приём заявок, идёт, завершён) —
секции листаются стрелками. Ниже: ближайшие и сыгранные матчи, сезонный зачёт очков, мини-профиль
вошедшего. Первый экран **редактируется оператором** — картинка, заголовок, подпись и кнопка;
пока баннер не задан, работает «герой по данным»: идёт приём заявок — зовёт заявиться, идёт
турнир — ведёт в него.

### Турниры

- список турниров карточками, **группировка по сериям** (LOST, кубки, прочие) и хронология;
- страница турнира: обзор, участники, регламент;
- **дивизионы** отдельными карточками с лимитом мест («8 из 12»);
- **таблица дивизиона** — очки, разница, места, зоны выхода;
- **групповая стадия** — сетки групп с кросс-таблицей и легендой зон;
- **плей-офф** — сетка на верхнюю и нижнюю;
- **статистика турнира** — топы по метрикам в разрезе дивизиона и стадии.

### Архив встреч и матчей

Лента всех встреч лиги с разрезами и листалкой; страница встречи с картами, счётом и составами;
постгейм-отчёт по каждому матчу — по ID из Dota 2, с выгрузкой картинкой.

### Ростер лиги

Два самостоятельных раздела — **Команды** и **Игроки**. У каждого разрезы «Сквозной / По
турнирам», поиск по всей лиге, у оператора дополнительно «В пуле / Архив».

- **страница команды**: шапка, состав строками, места (кор/мид/саппорт), штаб, история встреч;
- **профиль игрока**: медаль ранга настоящими ассетами Dota 2, факты (позиция, MMR, город,
  возраст), сезонные очки, Spirit Shards, история команд и матчей.

### Правила и контакты

Регламент лиги `/rules`, контакты `/contact`.

## 4. Аккаунт и кабинет игрока

- **вход**: почта с паролем, Google, одноразовый код из телеграм-бота;
- **анкета новичка** — три шага, черновик пишется на сервер: ушёл и вернулся — ответы на месте;
- **привязка Steam** — профиль подтягивается по Steam OpenID;
- **привязка телеграма** — ботом, одной кнопкой;
- **привязка к существующему профилю** ростера, если человек уже играл в лиге;
- **кабинет**: свой профиль, правка данных, настройки, безопасность;
- **сброс забытого пароля без писем** — одноразовая ссылка на 30 минут в привязанный телеграм,
  либо её выдаёт оператор; смена пароля гасит все прежние сессии;
- **личные сообщения** между игроками и служебный канал лиги, с непрочитанным и присутствием.

---

## 5. Заявки и капитанский путь

- **заявка команды через телеграм-бота**: бот ведёт капитана по вопросам, собирает состав;
- **приглашения игрокам** — согласие подтверждается в кабинете;
- заявка ложится в очередь модерации; одобрение **заводит команду, игроков и состав** сразу;
- сборный вход `/apply` — при нескольких открытых наборах даёт выбрать турнир.

## 6. Проведение матча

### Fearless-драфт

Драфт героев без повторов по серии: баны, пики, fearless-пул переносится между картами.
Регламент карты — 3 бана на сторону, 16 ходов, пики змейкой.

### Лобби встречи

Комната на матч: приглашение служебным сообщением, стороны, **выбор капитана самими игроками**,
готовность, монетка на сторону, чат комнаты.

**Драфт руками капитанов**: ход вносит капитан своей стороны, право хода и очередь проверяются
на сервере, три таймера (банк на сторону + счётчик хода) считаются на сервере и переживают
перезагрузку. Не успел — автобан/автопик, даже если у обоих закрыты вкладки.

**Вид для трансляции**: борд целиком по ключу-ссылке, без входа — источник OBS куки не носит.

### Шоу-форматы

- **UNDERBEER 2.0** — шоу-драфт: капитаны по очереди разбирают ростер, с оверлеем для эфира;
- **single draft** — случайный герой по каждой характеристике;
- **1х1** — заглушка, формат разрабатывается.

---

## 7. Телеграм-бот

Собственный бот лиги: заявка команды квизом, привязка профиля, вход на сайт по коду,
напоминания, анкеты и опросы, выгрузка инфографики матча.

**Разговор бота редактируется без программиста**: нодовый флоу — граф реплик, кнопок и переходов
правится в админке на холсте с масштабом и панорамой, рядом — тайминги напоминаний. Есть
встроенный гайд оператора.

## 8. Служебная часть

Хаб `/admin` — четыре группы, внутрь каждой проваливаются:

| Группа | Инструменты |
|---|---|
| **Showmatch** | UNDERBEER 2.0 · single draft · fearless draft · 1х1 |
| **Ведение лиги** | турниры · импорт · модерация · команда лиги · TP · телеграм-бот · дубли профилей · ранги · анкеты |
| **Аналитика** | разбор матча · карта вардов · показатели сезона |
| **Инструменты** | архив серий · студия графики · тема оформления · баннер главной |

Ключевое по каждому:

- **Турниры** — мастер заведения по шагам, дивизионы, составы, регистрации, черновик не виден
  публике нигде;
- **Импорт одним экраном** — составы разбираются из таблицы сезона, анкеты дозаполняются из
  выгрузки CRM; оба механизма с превью перед записью;
- **Модерация** — анкеты и привязки: одобрить с заведением профиля или вернуть с причиной;
- **Дубли профилей** — похожие профили одного человека: объединить, переименовать, развести;
- **Ранги** — сверка с OpenDota одной кнопкой, видно, у кого изменился;
- **Команда лиги** — роли и раздача прав галочками, выдача ссылки сброса пароля;
- **Архив серий** — встречи и карты, отсюда статистика идёт в разрезы;
- **Тема** — цвета интерфейса правятся из UI.

**Уведомления оператору**: анкета новичка, привязка к профилю, заявка команды и правка профиля
приходят строкой в колокольчик тем, у кого есть право этой очереди, и ведут сразу на нужную
вкладку.

### Права

Двенадцать прав, роль плюс галочки: приём регистраций · назначение админов · правка ростера ·
удаление профилей · турниры · архив серий · начисление TP · анкеты · студия · UNDERBEER · тема ·
баннер · разбор матчей. Права режут и витрину, и адрес: чужая страница объясняет, какого права
не хватает, а не показывает пустой экран.

## 9. Данные и интеграции

- **OpenDota** — матчи, статистика игроков, ранги, карта вардов;
- **Steam Web API** — запасной источник матча, когда OpenDota недоступна, и связка аккаунтов;
- **медали рангов** — настоящие ассеты Dota 2, лежат в репозитории, хотлинка нет;
- **сезонные очки (TP)** — зачёт MVP, начисляет оператор, есть и командный рейтинг;
- **Spirit Shards** — вторая валюта: за участие в жизни лиги, со ступенями и лестницей прогресса;
- **нормирование картинок** — у каждого слота (лого, фото, баннер) своя норма и окно подгонки
  с безопасной зоной.

---

## 10. Студия графики

Сборка турнирной графики по данным ростера: шаблоны, редактор, генерация картинок,
рендер под выгрузку. Афиша матча или объявление состава собирается из живых данных, а не
рисуется руками в фотошопе под каждую встречу.

---

## 11. Платформа

- **Кит элементов** — собственная дизайн-система: компоненты живут в одной библиотеке, витрина
  Кита открывается прямо в админке;
- **светлая тема Light Clay**, Tailwind v4, адаптив на 390 / 1280 / 1440 проверяется на каждом
  этапе;
- **SEO**: у каждой публичной страницы свои метаданные из живых данных, `robots.txt`,
  `sitemap.xml` (353 адреса), OG-превью; служебное и личное закрыто от индексации;
- **безопасность**: пароли scrypt с солью, лимиты попыток входа, сессии с отзывом, служебные
  разделы закрыты и правами, и прокси;
- **встраивание** в чужой лендинг через iframe с контролем доменов.

## 12. В разработке

| Что | Состояние |
|---|---|
| **Боевой сервер: VPS, домен, HTTPS** | единственный блокер релиза; площадка не выбрана |
| **Кто главный по базе** | решение до открытия: в базе уже личные данные живых людей |
| **Значки TP и Spirit Shards** | ждёт референсов; медали рангов уже сделаны |
| **Сообщение игроку без аккаунта** | развилка: «спящий» аккаунт или очередь писем |
| **Бот на вебхуке** вместо long polling | после появления домена |
| **Свободные агенты в ростере** | новый разрез витрины |

## 13. Сознательно отложено

Не «не успели», а решено делать после открытия сезона, с причиной:

| Что | Почему |
|---|---|
| Тёмная эфирная тема | релиз идёт на светлом Ките целиком; тема — блок переопределений после |
| Полная английская версия | переводить имеет смысл устоявшийся UI |
| Генерируемые OG-картинки под матч и профиль | требует серверного рендера, на старте хватает одной |
| Формат 1х1 | формат разрабатывается, угадывать правила нет смысла |
| LLM-помощник по статистике | нет вопроса, на который он отвечает |
| Реестр баллов с интерфейсом | места и касты правятся в базе руками, на сезон терпимо |
| Вторая итерация чата | личка работает, остальное — развитие |

## 14. Как это поддерживается

Не только код: у проекта заведён процесс, который переживает смену исполнителя.

- **ТЗ на каждый этап** — один файл, с целью, границами, требованиями дизайна, SEO и критериями
  приёмки; отчёт идёт в журнал работ, а не в ТЗ;
- **роли**: кто пишет ТЗ, кто делает, кто проверяет вёрстку, кто принимает — разведены;
- **приёмка по чек-листу** `SMOKE.md` — прогон всего продукта ролями перед каждой выкладкой,
  последний дал 33 pass · 2 fail, оба закрыты;
- **журнал решений** — почему сделано именно так, с датами;
- **карта проекта** — где что лежит, чтобы новый человек не искал.
