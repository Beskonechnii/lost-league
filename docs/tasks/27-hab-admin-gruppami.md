# ТЗ 27: Хаб админки — группы отдельными страницами

**Статус:** ready
**Входит в MVP:** нет — все инструменты открываются с `/admin` уже сейчас, это плотность экрана

## Цель

Оператор, которому нужен один инструмент, не разбирает глазами два десятка плиток. Хаб `/admin`
показывает четыре группы (Showmatch · Модерация · Аналитика · Инструменты), каждая ведёт на свою
страницу с плитками своей группы. Закрыто, когда с `/admin` видны группы и очереди, а плитки
инструмента живут на странице группы.

## Контекст

- `web/src/app/(admin)/admin/page.tsx` — хаб: `toolGroupsFor(perms)` и `HubGroupedTiles`,
  все группы плитками на одном экране.
- `web/src/app/_components/tools.ts` — единственный реестр инструментов и групп (`TOOL_GROUPS`),
  оттуда же условие показа пилюли «Админ». Новый инструмент добавляется только туда.
- Индикаторы очередей: `QUEUE_TOOL` (`/admin/moderation`, число из `moderationQueues().total`)
  и `DUPLICATES_TOOL` (`/admin/duplicates`, `duplicatesCount()`) — сегодня бейджами на плитках хаба.
- Крошки служебной части рисует `(admin)/_components/admin-header.tsx`, первую ступень «Админ»
  подставляет сама.
- **Решение Стаса 16.09.2026: вариант B.** Правило `UI-GUIDELINES` §0.1 «хаб над хабом запрещён»
  этим решением отменяется — блок в `DECISIONS.md` от 16.09.2026, стандарт поправлен.

## Scope

**Входит:**
- `/admin` — страница групп: четыре входа вместо двух десятков плиток.
- Страница группы со своими плитками, крошки «Админ / <группа>».
- Право по-прежнему решает видимость: плитка без права не рисуется, группа без единой доступной
  плитки не показывается ни на `/admin`, ни ссылкой.
- **Очереди видны с `/admin`, не проваливаясь внутрь:** число ожидающих модерации и число дублей
  доходит до верхнего экрана. Иначе единственный сигнал «есть работа» уезжает на второй клик,
  и хаб групп делает оператора слепым — ради этого сигнала он и открывает `/admin`.
- Возврат на хаб прежний — пилюля «Админ» в баре, активная на всём служебном дереве.

**НЕ входит:**
- Состав инструментов и их распределение по группам — остаётся как в `TOOL_GROUPS`, переклейка
  инструментов по группам здесь не обсуждается.
- Переименование инструментов (долги про «Управление турнирами» и «Анкеты» — строки `later`
  в `BACKLOG.md`): имя чинится отдельно от навигации.
- Поиск по инструментам — в баре уже есть общий поиск.
- Возврат сайдбара в любом виде — отменён решением 13.09.2026.

## Требования · DEV

- Источник групп и плиток — тот же `_components/tools.ts`. Второго списка не появляется: добавленный
  туда инструмент обязан сам встать на страницу своей группы.
- Адреса страниц групп строятся из реестра, а не перечисляются руками в маршрутах.
- Права проверяются на самих страницах групп, а не только витриной: прямой заход в группу без
  единого доступного инструмента даёт отказ, а не пустой экран.
- `(admin)` целиком остаётся `noindex` — как сейчас.

## Требования · DESIGN

Заполняет роль `design`: вид входа в группу на `/admin` (плитка группы, её размер и описание),
место и вид индикатора очереди на уровне группы, раскладка страницы группы на 390 / 1280 / 1440,
состояния «в группе один инструмент» и «доступна одна группа».

## Требования · SEO

Не требуется: служебная часть закрыта от индексации метаданными группы `(admin)`.

## Acceptance criteria

- [ ] `/admin` под владельцем показывает четыре входа групп и ни одной плитки инструмента.
- [ ] Клик по группе «Модерация» открывает её страницу со всеми плитками модерации из `TOOL_GROUPS`;
      крошки показывают «Админ / Модерация».
- [ ] Пилюля «Админ» в баре с любой страницы группы и с любого инструмента возвращает на `/admin`.
- [ ] Число анкет в очереди и число дублей видно **на `/admin`** и совпадает со списками на
      `/admin/moderation` и `/admin/duplicates`.
- [ ] Админ с правами только одной группы видит на `/admin` только её; прямой заход на страницу
      чужой группы даёт отказ, а не пустой список.
- [ ] Аккаунт-игрок пилюли «Админ» не видит, прямой заход на `/admin` и на страницу группы даёт отказ.
- [ ] Инструмент, добавленный строкой в `TOOL_GROUPS`, появляется на странице своей группы без
      правок в других файлах (проверяется временной строкой, убирается после проверки).
- [ ] `npx tsc --noEmit` и `npm run lint` чисто, `npm run build` проходит.
- [ ] 390px, **1280px** и 1440px без горизонтального переполнения.
