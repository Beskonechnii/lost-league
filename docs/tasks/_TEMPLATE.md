## Требования · DESIGN

## Требования · SEO

Заполняет роль `seo`. Только для публичной части: `metadata`/OG, URL, индексируемость,

## Acceptance criteria

Проверяемые пункты — по ним роль `qa` даёт pass/fail. Формулировка «действие → наблюдаемый
результат», без «работает корректно».

- [ ] …
- [ ] `npx tsc --noEmit` и `npm run lint` чисто, `npm run build` проходит
- [ ] 390px, **1280px** и 1440px без горизонтального переполнения. 1280 — не третья точка «для
      надёжности», а единственная ширина, где хром работает в режиме, которого нет ни на 390,
      ни на 1440: полный ряд разделов при минимуме места (ниже него разделы уходят в лист, то есть
      в тот же режим, что на 390). Ровно в эту дыру провалился сдавленный бар на 1024
- [ ] права: чужое недоступно, admin без права получает отказ
