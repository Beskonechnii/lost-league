# TEST-DRIVE — что появилось 03–17.09.2026 и как это прогнать

Тест-драйв для Стаса: пройти продукт насквозь ролями и увидеть своими глазами всё, что
сделано за две недели. Это **не** приёмка — приёмка живёт в `docs/SMOKE.md` и её гоняет `qa`.
Здесь другое: короткий маршрут по новому, с указанием, где смотреть и что должно получиться.

Порядок не случайный: сценарии идут так, как их проходит живой человек. Можно брать блоками.

---

## Прежде чем начать

```bash
cd web && npm run dev
```

Открывать **только через `localhost`** — на `127.0.0.1` Next 16 блокирует dev-ресурсы, гидрация
не проходит, ни одна кнопка не работает.

**Важно про dev-сервер.** Тот, что висит на 3000, запущен с `DEV_LOGIN_EMAIL` в окружении
процесса (в самом `web/.env` переменная пуста) — локально сессия сама выдаётся этому аккаунту,
когда куки нет. Это удобно для админки и **делает невозможной проверку прав**:
даже запрос без куки обслуживается как владелец. Всё, что про гостя и про отказы, смотреть на
прод-сборке:

```bash
cd web && npm run build && NODE_ENV=production npx next start -p 4203
```

Там автовхода нет по коду.

**Чего локально не будет.** Steam не работает (`STEAM_API_KEY` пуст), инфографику слать некуда
(`TG_CHAT_ID` пуст). Токен бота заведён — бота можно поднять: `cd web && npm run bot`. Пункты, которые в них упираются,
ниже помечены значком 🔌 — их гонять после того, как заведены ключи или данные
(`docs/MANUAL-TASKS.md`).

## 2. Новый игрок — вход и анкета

1. **Регистрация** — `/me`, вкладка регистрации. Пароль короче 10 символов отбивается, аккаунт
   при этом не заводится.
2. **Анкета** — три шага. Уйти со страницы на середине и вернуться: анкета открывается на том же
   шаге, ответы предыдущих шагов на месте (черновик пишется на сервере по нажатию «Далее»).
   Оговорка: ответы **внутри текущего шага**, не подтверждённые «Далее», теряются.
3. **Привязка Steam** 🔌 (нет ключа) и **телеграма** — в анкете и в кабинете. Телеграм
   прогоняется: бот поднимается, токен есть.
4. **После отправки** — `/me` показывает welcome: «Заявка на модерации» и блок «Что можно уже
   сейчас», а не тупик.
5. **Сброс пароля** — `/login/reset`:
   - ответ формы **одинаков** для заведённой и незаведённой почты (иначе форма подтверждала бы,
     что аккаунт есть);
   - ссылка приходит в привязанный телеграм — работает при поднятом боте, но **проверить не на
     ком**: в базе нет ни одного аккаунта с привязанным телеграмом. Сначала привязать свой;
   - ссылка одноразовая, живёт 30 минут: повтор по использованной и просроченная дают **экраны
     отказа**, а не всплывашку;
   - слабый пароль на форме сброса токен **не сжигает**.
6. **Смена пароля гасит прежние сессии** — `/me/settings`. Сменить пароль и открыть сайт со
   старой куки (другой браузер): выкидывает на вход.

## 3. Капитан

Сборка заявки квизом, приглашения состава и согласие игроков. Токен бота в `.env` уже есть,
так что блок прогоняется: поднять бота `cd web && npm run bot` (лог — `npm run bot:log`).
Упирается не в ключи, а в данные: в базе нет ни одной заявки команды и нет второй команды
с одобренным капитаном.

Что можно посмотреть без бота: лобби встречи `/lobby` — комната, стороны, выбор капитана,
готовность, монетка, драфт руками капитанов с тремя таймерами и ОБС-вид борда по ключу-ссылке.

## 4. Оператор — служебная часть

Заходить с аккаунта владельца.

### Хаб админки переделан

`/admin` — **четыре входа в группы** вместо стены из двадцати плиток (полотно на телефоне
упало с 4361 до 903px):

| Группа | Адрес | Что внутри |
|---|---|---|
| Шоуматч | `/admin/showmatch` | UNDERBEER, single draft, 1х1, fearless draft |
| Ведение лиги | `/admin/league` | турниры, импорт, модерация, команда лиги, TP, бот, дубли, ранги, анкеты |
| Аналитика | `/admin/analytics` | разбор матча, варды, показатели |
| Инструменты | `/admin/tools` | архив серий, студия, тема, **баннер главной** |

Смотреть: очереди на карточке группы показаны **словом** («1 дубль», а не «1»); крошки
«Админ / Ведение лиги / Модерация» подставляются сами из реестра; ряд «Другие группы» внизу.
Группа «Модерация» переименована в «Ведение лиги» — иначе крошки повторяли слово дважды.

### Баннер главной — новое

`/admin/banner` (право `banner`): картинка, заголовок, подпись, надпись кнопки и её адрес.
Проверить:
- заполнить всё и включить — картинка встаёт на место акцентной плашки на `/`;
- выключить тумблер — главная возвращается к герою по данным;
- оставить одно поле пустым — то же самое: баннер перекрывает герой **только целиком**.

Картинка нормируется как остальные: слот `home-banner` 1600×540, в окне подгонки видна
безопасная зона. На телефоне обрезается 38% ширины — важный текст держать внутри пунктира.

### Уведомления оператору — новое

Четыре события приходят строкой в колокольчик тем, у кого есть право этой очереди: анкета
новичка · привязка к профилю · заявка команды · правка профиля. Строка ведёт сразу на нужную
вкладку `/admin/moderation`.

Как увидеть живьём: с другого аккаунта поправить профиль → у владельца загорается колокольчик,
строка «Правка профиля от …» и переход на вкладку очереди.

Тут была самая неприятная находка приёмки: **служебным аккаунтом лиги был помечен аккаунт
владельца**, а лига сама себе не пишет — то есть уведомления не работали вообще. Заодно из-за
этого владельцу нельзя было написать в личку, а его имя в базе затёрлось на «Spirit CTRL».
Теперь «Spirit CTRL» — отдельный аккаунт без входа.

### Остальное по служебной части

- **Правка счёта встречи** → сразу видна в таблице дивизиона.
- **Лимит дивизиона** — «8 из 12» у дивизиона и суммой у турнира на `/tournaments`; запись сверх
  лимита просит подтверждения.
- **Группировка турниров по серии** — LOST первой группой, «Прочие турниры» последними.
- **Черновик турнира** не виден нигде: ни на главной, ни в списках, ни в `sitemap.xml`; прямой
  адрес даёт 404 и не выдаёт имя.
- **TP командам** — вкладка «Команды» на `/admin/tp`, ввод суммой с комментарием «за что».

## 5. Права — только на прод-сборке

Проверять на `next start`, не на dev (см. «Прежде чем начать»).

- гость и игрок на `/admin/*`, `/studio`, `/match`, `/underbeer` → редирект на `/me`, разметки
  с данными не отдаётся;
- админ **с одним правом** видит на `/admin` ровно одну группу, чужая страница группы объясняет,
  какого права не хватает, а не показывает пустой список;
- запись без права → 403 с названием права;
- чужая беседа → 403 «Это не ваша беседа»;
- чужой профиль подменой поля в форме не правится — адресат берётся из сессии;
- кука удалённого аккаунта даёт гостевую шапку и 403 на любую запись.

## 6. SEO — что изменилось под капотом

Смотреть не глазами, а ответом сервера (`curl -s <адрес> | grep -i '<title>\|robots'`):

- у каждой публичной страницы свой `title` и описание, у турнира, дивизиона, игрока, команды и
  встречи — живые, из тех же данных, что и сама страница;
- `/robots.txt` и `/sitemap.xml` появились (353 адреса, служебного нет);
- `/me`, `/chat`, `/login/*`, `/admin/*` — `noindex, nofollow`;
- разрезы витрин (`?by=tournament`, `?view=archive`) — `noindex, follow` + canonical на голый
  адрес, чтобы не плодить дубли;
- OG-картинка лиги 1200×630 отдаётся по умолчанию.

**Домен в код не зашит** — берётся из `BASE_URL`. Пока боевого адреса нет, в `sitemap.xml` и в
`og:image` стоит localhost. Это не баг, а ожидание ТЗ 01.
