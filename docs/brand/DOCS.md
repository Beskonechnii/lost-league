# Docs — League of Spirit (LOST)

Knowledge base проекта

## Что за проект

**LOST** (League of Spirits) — киберспортивные события по **Dota 2**. По сути маленькая **студия каста**.
- Локация: **Минск, Беларусь**.
- Формат: турниры сезонами (LOST S1 — завершён, LOST S2 — в работе; ранее — MTH, UNDERBEER).
- Масштаб S1: 4 группы, 20 команд, 100 игроков. Этапы: Group Stage → Show-match → Bonus Stage → Play-off → Final.
- Сайт-лендинг: https://leagueofspirits.ru/lost_s1 (на **Tilda**; таблица результатов сейчас на Google Sheets)
- Соцсети: Twitch, Discord, Instagram, Telegram, YouTube, TikTok.

## Позиционирование

**LOST кастует только свои турниры** — мы не студия-подрядчик под чужие ивенты (в отличие от модели Paragon).
→ Следствие: единый бренд; брендбук и оформление строим под себя, без требования «работать поверх чужого турнира».

## Партнёры

Спонсорство пока не подтверждено (кто именно спонсоры — уточняется):
- **Gorilla Energy** — энергетик (инфо в открытом доступе, собрать для презентаций).
- **«На Дне» Shot Bar** — бар.
- **Miller** — пивной напиток.

## Референсы продакшена

Ориентир — EN-направленные студии: **Paragon**, **BetBoom**, **ESL**.
Что изучаем в их продакшене:
- разного рода **HUD'ы**, **реплеи**, **баннеры**;
- **инфографика с лайв-аналитикой** (урон, застаканные лагеря и т.п.).

Подробный разбор конкурентов (форматы / визуал / монетизация) — см. [COMPETITORS.md](./COMPETITORS.md).

## Наша задача (определяет стек)

Построить **генеративный контент-пайплайн** + операционные инструменты (админка баллов, API-инфографика).
Стек генерации уточняем под задачи. **Операционная система (данные/флоу/треккинг):** Next.js + Prisma + SQLite, стата матчей — OpenDota, «бот» = веб-админка на сайте. Спека — [ARCHITECTURE.md](../../ARCHITECTURE.md).

## Инструменты

### HUD / оверлеи трансляции
- **LHM.gg** (Lexogrine HUD Manager) — **главный кандидат (проверить перед внедрением)** для лайв-инфографики: урон, разбивка золота, Рошан, курьер, эффективность линий, экраны драфта/пост-матча. На его движке работает премиум-HUD **ESL**.
- Решение: лайв-статистику **не писать с нуля** — брать готовый инструмент и красить под брендбук.
- **Цены (июль 2026, €/мес):**
  - Free — €0, но **только некоммерческое + вотермарк** → годится для теста, не для эфира.
  - Personal — €34.99 (1 устройство).
  - **Professional — €149.99** (3 устройства) → даёт **Premium HUD** для Dota 2.
  - **Ultra HUD** (тот самый, что у ESL) — только **Enterprise, от €59.99/место, мин. 3 места ≈ €180/мес**.
- Вывод: для коммерческого эфира минимум — **Professional (€150)** с Premium HUD, либо **Enterprise (~€180+)** ради Ultra HUD. Free — только тест.
- ⚠️ Ещё проверить: глубину кастомизации под брендбук, покрытие нужных метрик (в т.ч. застаканные лагеря), годовые цены.

## Медиакит — форматы для партнёров

Конструктор рекламных слотов: из него за 10 минут собираем персональную презентацию под Gorilla / Miller / «На Дне» (roadmap: «презентации для партнёров»).
**Ключевая идея: ежедневные операционные задачи = товар для спонсоров** (бот MVP → готовый слот «MVP от бренда»).

| Слот | Что это | Кандидат |
|------|---------|----------|
| Титульный спонсор | Имя бренда в названии турнира/сегмента | «LOST × Gorilla» |
| MVP матча от бренда | Лого + упоминание при награждении MVP (наш бот MVP) | Gorilla Energy |
| Пост-матч имени бренда | Заставка + плашка сегмента разбора | Miller |
| Логотип в оверлее / тикер | Ротация лого по углам, бегущая строка | любой |
| Офлайн-активация | Промо-зона, промокод на трансляции | «На Дне» Shot Bar |
| Соц-пакет | Co-branded посты, highlight-рилы | любой |
