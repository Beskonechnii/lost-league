## 1. Форматы контента

- **Лайв-эфир** = не только матч: драфт-фаза, **аналитик-деск**, пре-гейм, **пост-матч разбор** (ESL/PGL/BLAST).
- **YouTube VOD:** полные матчи, **highlights/recap**, hype-видео, интервью игроков, влоги (паттерн Team Secret/Liquid/Nigma), длинные разборы (BeyondTheSummit ~50 мин).
- **Shorts/TikTok:** короткие эпик-моменты, фильтры/челленджи (#BLASTTVMajor — 100M+ просмотров).
- **Спрос:** MOBA = ~60% часов просмотра на Esports World Cup — короткий клиповый контент тащит охваты.

→ **Для LOST:** минимальный контент-цикл на игровой день ложится ровно на ежедневные задачи roadmap:
`анонс игры → лайв со студийным деском → highlights + shorts → пост-матч + MVP`.

## 2. Визуал и продакшн

- **HUD с live-аналитикой — стандарт топов.** ESL Ultra HUD (на движке **LHM.gg**): урон, эффективность/движение линий, разбивка золота, Рошан, курьер, застаканные лагеря.
- **Брендированные оверлеи:** lower-thirds, тикеры, рамки, transition-экраны, вращающиеся 3D-джерси (приём StarLadder).
- **Узнаваемая студийная сцена** (PGL Studio, BLAST studio shows) — сцена сама по себе часть айдентики.

→ **Для LOST:**
1. **Лайв-инфографику не строить с нуля** — взять/настроить готовый HUD (LHM.gg). Это закрывает пункт roadmap «После MVP: лайв-инфографика (урон, лагеря)».
2. Единый **пакет оверлеев** (плашки, тикер, рамки, transition) — в брендбук.

## 3. Монетизация и партнёры

- **Титульный спонсор / naming** турнира (модель BetBoom Dacha).
- **Брендированные сегменты:** Play of the Game, **MVP Award**, «[Brand] Post-Match Analysis» — прямое попадание в наших спонсоров.
- **Оверлей-ассеты:** ротационные логотипы по углам, тикеры, рамки.
- **Соц-активации:** co-branded посты, story takeover, брендированные highlight-рилы.
- **Мерч / диджитал-джерси.**

→ **Для LOST:** спонсорские слоты уже ложатся на ежедневные задачи. Наши партнёры → форматы:
- **Gorilla Energy** → «MVP матча от Gorilla» (наш пункт «назначение MVP через бота» = готовый спонсорский слот).
- **Miller** → «Разбор дня от Miller» / пост-матч-сегмент.
- **«На Дне» Shot Bar** → офлайн-активация / промо на трансляции.
- Собрать **медиакит** с этими форматами (roadmap: «презентации для партнёров»).

## Куда стримиться (бенчмарки-цели)

1. **Мультиплатформенный симулкаст** (Twitch + YouTube + Kick + Dota TV + ВК) — модель BetBoom.
2. **Позиционирование Paragon:** студия-талант, способная кастовать не только свои турниры.
3. **Планка продакшна:** узнаваемая сцена + брендбук-консистентный HUD (ESL/PGL/BLAST).
4. **Entertainment-first + shorts-машина** (BLAST) — охваты берём клипами.
