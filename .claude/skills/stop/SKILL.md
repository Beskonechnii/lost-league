# stop — снять локальные dev-серверы

```
bash .claude/skills/stop/stop.sh
```

Скрипт печатает, что именно снял. Доложи пользователю коротко: какие порты освобождены.

## Что он трогает и что нет

- **Гасит:** `next dev` / `next-server` этого репозитория и любые процессы, слушающие
  порты 3000–3010 (следующий свободный порт занимает `npm run dev`, см. `web/scripts/dev-port.mjs`).
- **Не трогает:** телеграм-бота (`npm run bot:down`), прод-контейнер и туннель (скилл `serve`,
  снятие — `.claude/skills/serve/stop.sh`).
- **Данные не теряются:** база — файл `web/prisma/dev.db`, sqlite пишет на диск в момент запроса.
  Незакоммиченные правки кода тоже на месте — это не контейнер.
