# kit — открыть макеты LOST

Дизайн живёт в артефактах claude.ai, а не в репозитории. Каждый новый чат раньше приходилось
листать галерею и угадывать нужные URL — этот скилл держит адреса у себя и открывает всё одной
командой. Правило канона — в памяти `design-mockup.md`: **правим по тому же URL, дубли не плодим.**

## Канонические артефакты

| Макет | URL |
|---|---|
| **Кит элементов** (ЭТАЛОН стиля + библиотека компонентов, см. правило ниже) | https://claude.ai/code/artifact/de74082f-62a9-46ca-b381-b12a204ab6d1 |
| **Вход** (окно входа/регистрации, соц-входы, квиз) | https://claude.ai/code/artifact/8176d21a-57ec-4d94-9a9c-fc6eec616b73 |
| **Сайдбар** (навигация, свёрнутое состояние) | https://claude.ai/code/artifact/bb6475ff-7f42-4e05-839d-092cb8f90fe0 |
| **Профиль игрока** (страница: hero + две колонки блоков, карьера бубликом) | https://claude.ai/code/artifact/922f9cb2-a916-4434-bae2-42eb2670f7cc |

**Кит элементов — эталон стиля и библиотека компонентов.** Стиль: тёплая бумага `#E7E3D8`,
ink `#33322E`, мятный акцент, пластилиновые тени `--sh-raise/--sh-mint/--sh-carve`, шрифт Nunito.
Разделение:

- **Новый компонент/атом** (строка, чип, бублик, мини-карточка…) — **добавляем в Кит** отдельным
  артбордом-витриной (напр. «Профиль · атомы»), чтобы переиспользовать и детально править. Именно
  для этого Стас и просит «добавь элементы в кит».
- **Новый экран целиком** (профиль игрока, вход…) — **отдельный артефакт**, не артборд внутри Кита.

Кит правится через извлечение рабочих файлов: `seed-canvas.mjs --extract <saved> --to <dir>` →
правка/добавление `*.dc.html` + `canvas.json` → пересборка `seed-canvas.mjs --template … --artboard …`
→ republish по тому же URL (`contract: "0.1.31"`, capabilities не передаём — канвас держит своё).
Правь по чистой извлечённой копии, существующие артборды не ломай.

## Шаги

### 1. Открыть

По умолчанию — только тот макет, что назвал Стас. Если сказал «открой кит/макеты» без уточнения —
открывай все три. Каждый через `Artifact read` по URL из таблицы: свой макет читаем raw HTML
(полотно сохраняется в локальный файл, его путь — в ответе), с ним и работаем.

### 2. Править

Правки — правкой локального файла + republish **по тому же URL** (`Artifact` с тем же `url`,
не новым `file_path`-адресом). Новый артефакт не создаём: у макета один адрес, его и обновляем.
Заголовок (`<title>`) и favicon держим стабильными между republish — иначе в галерее это читается
как другая страница.

### 3. Плейсхолдеры

В макетах — только нейтральные плейсхолдеры, без личных данных Стаса (память `no-personal-data`).

## Правила

- **URL — источник истины.** Если завёл новый канонический макет — допиши строку в таблицу выше,
  чтобы следующий чат его тоже знал.
- Не листай галерею `Artifact list`, пока URL есть здесь. Листание — только если Стас просит
  макет, которого в таблице нет.
- Тексты в макетах — по-русски. Стиль макетов — **Light Clay** из Кита (тёплая бумага, мятный
  акцент), а не тёмная тема продукта. Дизайн ориентируется на Кит, а не на текущий прод-UI.
