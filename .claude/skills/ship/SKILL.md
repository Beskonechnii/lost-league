# ship — WORKLOG → commit → push (репозиторий LOST)

Сессия закрывается так, чтобы следующая (на этом компе или в облаке с телефона) поняла
состояние **без этого чата**: всё, что не в git, после облачной сессии исчезает.

## 1. Запись в WORKLOG

Допиши **сверху** (новейшее первым) по формату верхней записи — `sed -n '1,30p' WORKLOG.md`,
файл целиком не читай. ≤5 строк: что сделано · файлы · что проверено · **`Дальше:`**.

Строка `Дальше:` обязательна — именно она спасает, когда сессия рвётся на лимитах или
Стас продолжает с другого устройства (за две недели такое было шесть раз,
`docs/PROCESS-REVIEW.md` §6). Этап не закончен — так и напиши: «не доделано: …».
Не проверял в браузере — тоже напиши. Честная запись полезнее красивой.

## 2. База — только в облачной сессии

```bash
[ -n "$CLAUDE_CODE_CONTAINER_ID" ] && echo облако || echo локально
git status --short web/prisma/dev.db
```

В облаке `web/prisma/dev.db` **не коммитится** (бинарник не мержится, на компе база почти
всегда новее): `git checkout -- web/prisma/dev.db`, а в отчёте скажи, что её меняло. Были
осмысленные изменения данных — останови передачу и спроси Стаса: либо снимок
(`npm run db:export` → `data/snapshot.json`, текст мержится), либо повтор действия на компе.
Схема и миграции коммитятся всегда. На компе база коммитится как обычно.

## 3. Коммит и пуш

Сам коммит делает сабагент `ship` (Haiku): три git-команды и сабж по диффу не стоят модели
посильнее, а сабагент считается отдельно.

```
Agent(subagent_type: "ship", run_in_background: false,
      description: "Коммит и пуш",
      prompt: "Закоммить и запушь текущие изменения репозитория LOST.")
```

Сабж он формулирует сам из диффа — **не пиши сообщение за него**, иначе экономии не будет.
Было решение, которого по диффу не видно (почему такой подход, что отбросили), — добавь одной
фразой в `prompt`.

## 4. Ответ Стасу

Одна строка: SHA, ветка, число файлов, сабж. Плюс вторая, если работа продолжится на другом
устройстве: там нужен `git pull` (работа в `main`) и `pickup`.

## Что помнить самому

- **`main` — рабочая ветка**, пуш штатный (решение 24.08.2026 при переезде на репо `lost-league`).
  Переспрашивать не нужно.
- Ветку сабагент не переключает: пушится текущая.
- Упал хук — не обходить `--no-verify`, разбираться с причиной.
- Дерево в конце чистое. Мусор по ходу (патчи, дампы, скриншоты) — удалить до коммита.
- `node_modules` / `.env` / `web/src/generated` — не коммитятся никогда.
- Remote: `origin` → github.com/Beskonechnii/lost-league (приватный).
